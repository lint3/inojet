# INOJET

A quicker way to use Inonet.

## Setup

1. Set your auth cookie using `config token`.
2. Set your session ID using `config sessionid`.
3. Set your username using `config username`.
4. Set your config path if desired using `config path`.
5. Save your settings: `config save`

## Retrieve Data

```
refresh customers
refresh assemblies $MY_CUSTOMER
```
